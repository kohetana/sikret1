## Коротко
SQL (Structured Query Language) — декларативный язык запросов к реляционным базам данных. Создан в IBM в 1970-х годах, стандартизирован ANSI/ISO, живёт более 50 лет и остаётся главным языком работы с данными.

## Происхождение
- 1970 — Эдгар Ф. Кодд (IBM) публикует статью «A Relational Model of Data for Large Shared Data Banks», закладывающую основы реляционной модели.
- 1974–1977 — Дональд Чемберлин и Рэй Бойс (IBM San Jose Research Laboratory) создают язык SEQUEL (Structured English Query Language) для экспериментальной СУБД System R.
- 1977 — SEQUEL переименован в SQL (из-за конфликта торговой марки).
- 1979 — Relational Software Inc. (позже Oracle) выпускает первую коммерческую реализацию SQL.
- 1986 — ANSI принимает SQL как стандарт; 1987 — ISO.
- 1992 — SQL-92, важнейший стандарт, закрепивший язык в корпоративной практике.

## Исходная проблема
До SQL доступ к данным требовал навигации по структурам (сетевые и иерархические модели, как в IMS). Кодд предложил реляционную модель: данные — это таблицы, а запросы — операции над множествами. SQL сделал доступ к данным декларативным: пользователь описывает результат, а СУБД сама выбирает план выполнения.

## Пользователи и области применения
- Системные аналитики, администраторы БД, разработчики приложений, бизнес-пользователи.
- Банки, страхование, государственные системы, ERP, CRM, BI, веб-приложения, аналитика, Data Science.

## Ключевые вехи
1. 1970 — статья Кодда, начало реляционной модели.
2. 1974–1977 — System R и SEQUEL/SQL в IBM.
3. 1979 — Oracle V2, первая коммерческая СУБД с SQL.
4. 1986/1987 — стандартизация ANSI/ISO.
5. 1992 — SQL-92, важнейший стандарт.
6. 1995 — MySQL, массовый открытый SQL для веба.
7. 2000-е — LAMP, PostgreSQL, Microsoft SQL Server, BI.
8. 2010-е — NoSQL-вызов и ответ SQL (NewSQL, распределённые СУБД).
9. 2020-е — облачные СУБД, SQL поверх Data Lake, аналитика.

## Важные платформы, продукты и проекты
IBM System R, Oracle, DB2, SQL Server, MySQL, PostgreSQL, SQLite, Teradata, Snowflake, BigQuery, Redshift.

## Почему объект был ценен в выбранную эпоху (1986–1992)
- SQL стал единым стандартом ANSI/ISO, что позволило переносить знания между СУБД.
- Корпоративные системы (банки, страхование, государство) массово переходили на реляционные СУБД.
- SQL-92 закрепил синтаксис, который изучают до сих пор.
- Декларативность снизила порог входа для аналитиков и бизнес-пользователей.

## Факты для рекламной концепции
- SQL — «латынь данных»: его понимают все СУБД.
- Один запрос может заменить сотни строк процедурного кода.
- SQL не спрашивает «как», он спрашивает «что».
- «Данные — новая нефть, а SQL — буровая установка» (шутка более поздней эпохи, но хорошо ложится в рекламный голос).
- Стандарт ANSI/ISO — гарантия совместимости.

## Что осталось спорным
- Точная дата переименования SEQUEL → SQL (1977 или 1979).
- Кто «первый» коммерческий SQL: Oracle или IBM.
- Насколько SQL соответствует реляционной модели Кодда (критика Кодда и Дейта).
