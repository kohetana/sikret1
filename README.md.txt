## Как открыть
Открыть index.html в браузере (двойной щелчок). Интернет не требуется.

## Коротко о проекте
Одностраничный рекламный сайт вымышленного учебного центра «DataLine», 
предлагающего курсы SQL для системных аналитиков и администраторов БД в эпоху стандартизации ANSI/ISO. 
Страница передаёт атмосферу мейнфреймов, терминалов 3270 и корпоративной рекламы конца 1980-х — начала 1990-х. 
Центральная идея: SQL — декларативный язык, который понимают все машины, и он говорит с данными на одном стандарте.
